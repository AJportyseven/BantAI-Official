BantAI is astudent project.

Hello, I am AJ Domingo, a 4th year Bachelor of Science in Information Technology student. BantAI is my capstone project.

I worked on it by myself, from the first plan to the installer you can download. There is still a lot I am learning, and this page is a simple account of how it was made.

Made to learn.Not made to sell.

BantAI is a school project. I made it to learn how a real system is planned, built and finished, and to show what I have learned so far.

It was made for educational purposes only. It is not for sale, and it is not meant to replace anyone's judgement. A person always makes the final decision.

What I worked on.

I worked on BantAI by myself, so each part below was my job. Some parts were harder than others, and I learned something from all of them.

  • Planning and design

    I decided what BantAI should do, what it must never do, and how every screen should look.

  • The proctor's console

    The screens where a proctor watches a session and reviews each flagged moment and decides what to do.

  • The detection

    The part that looks at the camera picture and notices head turns, movement and objects.

  • The records

    The part that saves each session and each flag on the same computer.

  • The installer

    The package that puts BantAI on a Windows computer.

  • This website

    Every page, from the layout to the animations.

How it was made.

Not everything worked the first time. This is the story in the order it happened.

  1. Step 01

    Setting the rules

    Before building I set the rules. BantAI runs offline, records no audio, never recognises faces, and leaves every decision to a person.

  2. Step 02

    Teaching it to see

    I used open source models so the program could find people and objects in a camera picture and keep track of each person on screen.

  3. Step 03

    Building the console

    I built the part that stores each session, and the screens where a proctor reviews every flagged moment and decides what to do.

  4. Step 04

    The version that failed

    My first live video design made the computer run out of memory and freeze. I started that part again. BantAI now keeps one watermarked photo at the moment of a flag instead of video.

  5. Step 05

    A Windows desktop app

    I packaged BantAI as a Windows desktop app and added support for USB and network cameras.

  6. Step 06

    Version 1, then Version 2

    Version 1 is ready as a Windows installer. Version 2 is still in progress and is not available yet.

What I used.

Here is what each one does, without the jargon.

  • Python

    The language the main program is written in.

  • FastAPI

    Lets the screens and the detection pass messages to each other on the same computer.

  • SQLite

    A small database that keeps sessions and flags on the computer.

  • YOLOv8

    An open source model from Ultralytics that finds people and objects in a picture.

  • HTML, CSS and JavaScript

    The console screens and this website.

  • PyInstaller and Inno Setup

    Wrap the program into one installer for Windows.

Detection and pose estimation use YOLOv8n and YOLOv8 Pose from Ultralytics, licensed under the GNU Affero General Public License v3.0. Source repository: github.com/ultralytics/ultralytics
