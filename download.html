Questions

Classroom setup and more questions→

Does it need the internet?

No. BantAI runs offline on the computer it is installed on.

Does it record video?

No continuous video is stored. It saves a watermarked snapshot when a flag triggers.

Which cameras can it use?

A USB UVC webcam or an RTSP IP camera. The minimum is 720p over USB 2.0. 1080p over USB 3.0 or RTSP is recommended.

Windows shows a notice when I run the installer.

Windows can ask you to confirm an installer it does not recognise. Continue only if you downloaded the file from this page and the file name and size match step two.
